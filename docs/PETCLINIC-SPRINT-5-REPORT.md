## 1. Outcome and scope

**Investigation outcome: new finding (application-constraint interpretation)**

One defect reproduced twice on Spring Petclinic commit `818c413`:
`PetValidator.validate()` skips the type-required check for existing pets
(those for which `pet.isNew()` is `false`). Submitting the edit-pet form with
a blank type returns HTTP 302 (redirect, success) instead of HTTP 200 with a
validation error. Two independent test runs confirmed the failure. A candidate
fix removes the `pet.isNew()` guard; the unchanged reproducer and the full
upstream baseline test suite (plus the two new reproducer tests) pass on the
candidate. The developer approved the patch for publication on a separate Vesper
branch. Upstream Petclinic has not been modified.

The expectation is based on the H2 schema (`pets.type_id INTEGER NOT NULL`),
the existing `PetValidator` create-path logic, and the shared
`createOrUpdatePetForm`. It is an application-constraint interpretation; no
separately approved stakeholder specification document exists for this finding.
This is acknowledged as an open limitation of the investigation's documented scope.

## 8. Suspected problem and code location

**Suspected problem:** `PetValidator.validate()` guards the type-required check
with `pet.isNew()`, so the check is silently skipped when editing an existing pet.
A POST to the edit-pet form with `type=` (blank) returns HTTP 302 (redirect to
owner page) instead of HTTP 200 with a bound `type` field error.

**Code location:** [`PetValidator.java`](https://github.com/spring-projects/spring-petclinic/blob/818c4136ea971c21674525f9053de0d9c7ad8cfe/src/main/java/org/springframework/samples/petclinic/owner/PetValidator.java), line ~51:


## 11. Proposed fix, rationale, and exact diff

**Rationale:** The type-required check should apply regardless of whether the pet
is new or existing. The H2 schema enforces `NOT NULL`; the edit path should enforce
the same constraint at the application layer.

**Exact diff** (from `evidence/petclinic-sprint4-20260926/candidate.patch` — git `7aa3a03`):

```diff
--- a/src/main/java/org/springframework/samples/petclinic/owner/PetValidator.java
+++ b/src/main/java/org/springframework/samples/petclinic/owner/PetValidator.java
@@ -48,7 +48,7 @@ public class PetValidator implements Validator {
 		}
 
 		// type validation
-		if (pet.isNew() && pet.getType() == null) {
+		if (pet.getType() == null) {
 			errors.rejectValue("type", REQUIRED, REQUIRED);
 		}
```

Only one production line changes. Existing tests, build files, and dependencies
are unchanged. The reproducer test is added to both original and candidate
